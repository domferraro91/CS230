# CS230
Operating Platforms 2026 SNHU
Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?
The client is The Gaming Room, a company that wants to set up their game, Draw It or Lose It, to work on multiple platforms such as Windows, macOS, Android, and iOS.

What did you do particularly well in developing this documentation?
I believed I did well with being thorough throughout the document, and explaining the options that the company has and my recommendations as well.

What about the process of working through a design document did you find helpful when developing the code?
While writing the code, it was helpful going through the document to see the requirements needed for the application, as well as referencing the UML diagram and making sure the classes are being built correctly and to specification.

If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?
I am pretty happy with how the entire document turned out. I think if anything, I would like to have learned about the System Architecture View and would have filled out that segment of the document.

How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?
I thought of myself as a user of the software, and considered what I would want when interacting with the program. The user needs quality security for their information, quick and easy access to the game, and an overall enjoyable gaming experience. It is very important to consider the user's needs when designing because they are the end user, they are the one that the game is realistically being built for, and if it is not going to be an enjoyable experience for the user, then in my opinion, you have failed to create a successful application.

How did you approach designing software? What techniques or strategies would you use in the future to analyze and design a similar software application?
Starting with creating a UML diagram and the software design template, it helped create the code needed for the application. I think in the future, It would be wise of me to consider doing the same. Creating the UML diagram was a good way of brainstorming for what the application requires, and makes it considerably easier than just starting in the IDE and writing code as I go along.
